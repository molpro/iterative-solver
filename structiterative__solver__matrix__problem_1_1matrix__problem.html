Detailed Description

A specialisation of the Problem class for linear problems in which the kernel matrix is stored in full in an existing array.

procedure, pass diagonals (this, d)
 Optionally provide the diagonal elements of the underlying kernel. If implemented and returning true, the provided diagonals will be used by the base precondition() function for preconditioning (and therefore the precondition() function does not need to be reimplemented), and, in the case of linear problems, for selection of the P space. Otherwise, preconditioning will be done with precondition(), and any P space has to be provided manually.
