Detailed Description

template<class AL, class AR>
class molpro::linalg::array::ArrayHandlerDDiskIterable< AL, AR >

Array handler between a distributed array (left), typically one held on disk, and a contiguous array (right), e.g. std::vector or Span.

This is ArrayHandlerIterableDDisk the other way round, see there for how the arrays are accessed.

A new distributed array made as a copy of a contiguous one is created by a copy function. By default, this is AL::CreateTempCopy() on molpro::mpi::comm_self(), because the contiguous array is not distributed, optionally with a directory for the file.

The hermitian inner product <x|y>: conjugate-linear in x, linear in y.

For a real element type this is the ordinary dot product; for a complex one the left argument is conjugated, so that dot(x, x) is real and non-negative and an overlap matrix built from it is hermitian rather than complex symmetric.
