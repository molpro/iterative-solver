Dispatches to ?syevd/?heevd for the scalar types LAPACK covers and to Eigen::SelfAdjointEigenSolver for every other precision; both branches produce the same layout and ordering.

Parameters

[out]eigenvectorsthe eigenvectors as the columns of a column-major matrix, i.e. eigenvector i occupies elements [i*dimension, (i+1)*dimension). Same size as matrix.
[out]eigenvaluesthe eigenvalues in ascending order. Must be dimension elements long.
[in]dimensionlength of one axis of the matrix.
Returns
status. If 0, successful exit. If -i, the ith argument had an illegal value. If i, the algorithm failed to converge.
