#include <helper-dispatch.h>

Detailed Description

Suspends floating-point exception traps and discards the flags raised in its scope. LAPACK's ?stemr relies on IEEE infinities from exactly-zero pivots (?larrc), which would otherwise trap if the host application enables FPEs.
