Detailed Description

template<class AL, class AR = AL>
class molpro::linalg::array::ArrayHandlerWithCopyFunc< AL, AR >

Base for handlers whose left arrays are created by a function given by the user.

Disk arrays may need information beyond the array being copied in order to be created, e.g. where to put the file, so that construction of a new left array as a copy of a right array is delegated to copy_func.
