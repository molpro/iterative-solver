Detailed Description

template<template< class, class, class > class Solver, class R, class Q, class P>
class molpro::linalg::itsolv::DavidsonCommon< Solver, R, Q, P >

Implementation shared by the linear Davidson solvers, LinearEigensystemDavidson and LinearEquationsDavidson.

Holds the management of the subspace between iterations: proposing new parameters from the preconditioned residuals, limiting the size of the Q space by moving deleted Q vectors into the D space, and periodically resetting the D space, together with the options that control it.

Proposes new parameters for the subspace from the preconditioned residuals.

After add_vector solves the subspace problem it returns the new solution and residual. The residual should be preconditioned, i.e. using Davidson method, to accelerate convergence. The updated residual is used in this function to propose new Q space parameters orthonormal to the old space. They are returned in parameters so that corresponding actions can be calculated and used in add_vector in the next iteration.

Every reset_D iterations, unless reset_D is 0 (the default) or there is no D space, the D space is reset instead (see detail::DSpaceResetter): the current solutions are returned in parameters as the new parameters, the D space is cleared, and for each returned solution the Q vector with the largest overlap with it is deleted. The Q space is then reduced to at most reset_D_max_Q_size vectors, including the returned solutions. If there are more solutions than parameters, the reset is spread over several iterations. Until the next add_vector() takes up the returned solutions, solution() is not available, as the subspace left may be too small to hold them; eigenvalues() and errors() still refer to the solutions before the reset. working_set() numbers the returned solutions 0, 1, ..., which in the later steps of a reset spread over several iterations are not the roots they belong to.

Once all roots have converged, the subspace is left unchanged.
